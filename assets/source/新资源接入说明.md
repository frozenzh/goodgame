# 新资源与场景节点

- 原图：`资源精灵图.png`、`角色四向动画帧.png`；`参考图.png` 仅作布局参考。
- 抠图：`new_house.png`、`new_workbench.png`、`new_farmer_front.png`、`new_pond.png`、`new_background.png`。
- 地块：`new_plot_locked.png`、`new_plot_cleared.png`、`new_carrot_seed.png`、`new_carrot_leaf.png`、`new_carrot_mature.png`。
- 角色动画：`actor_down_01.png` 至 `actor_up_04.png`，四方向各四帧。

场景入口为 `scenes/main/Main.tscn`。在 `scenes/world/StaticWorldStrip.tscn` 中，`StaticBackground/Landscape`、`PlotLayer/PlotNodes/Plot01..07`、`ResourceNodes/House|Workbench|Pond|ShopBuilding` 都是可手动调整的位置节点。建筑和地块直接按可见资源图片的不透明像素响应点击。角色节点在 `DynamicAnchors/Worker`；移动建筑后仍需检查 `DynamicAnchors/WorkerTargets` 中的角色目标点。

角色无待办时按 3–5 秒随机行走、1–3 秒停留循环；游荡范围以最近一次操作结束坐标为中心，范围和速度可在 `Worker` 节点检视器中调整。种植、开垦、制作、装备、交易、升级及钓鱼按钮只下达指令；指令保存在游戏状态中，角色抵达目标点后原地执行 3 秒，再调用系统结算。钓鱼启动后角色停留池塘，直到出现新指令或停止钓鱼。

地块默认仅右侧两块解锁。游戏运行时，地块外观以存档中的开垦和胡萝卜生长状态为准；编辑器内可通过每块地的 `unlocked` 与 `preview_stage` 预览。可用 `tools/export_sprite_cuts.py` 从两张原始精灵图重新导出全部透明 PNG。
