# 新手引导使用

## 当前实现

主游戏窗口中使用四块半透明黑色遮罩围出聚焦区域。聚焦区域保持可点击，外部区域的点击会被遮罩拦截。金色线框指示目标；木色对话框有“下一步”和“跳过”。步骤会跟随目标节点移动或随窗口尺寸更新。

新存档首次启动自动播放；已有存档按 **F1** 打开，播放中再按 F1 可关闭。暂时是说明式引导，推进依赖“下一步”，不会强制等待玩家完成种植等操作。

## 在 Godot 中调整外观

打开 `scenes/main/Main.tscn`，展开 `TutorialGuide > OverlayRoot`。这是静态场景，可以直接预览并调整：

- `Dialog`：移动和改变提示框大小；`Content/Title`、`Message`、`Actions` 分别控制标题、正文和按钮。
- `MaskTop`、`MaskLeft`、`MaskRight`、`MaskBottom`：调整 `Color` 的 Alpha 改变背景压黑程度。四块遮罩的**位置和尺寸**由运行时代码根据目标节点计算，无需手调。
- `FocusFrame`：在 Inspector 的 `Theme Overrides > Styles > Panel` 修改边框颜色、粗细和圆角。

示例步骤为展示不同位置，在 JSON 中填写了 `dialog_position`。若想统一采用编辑器中 `Dialog` 的位置，删除各步骤的 `dialog_position` 字段即可。

## 新增引导步骤

编辑 `data/tutorial/intro.json` 中的 `steps` 数组。每条步骤可填写：

```json
{
  "id": "house",
  "target_path": "StaticWorldStrip/ResourceNodes/House/LevelVisuals/Level1",
  "title": "小屋",
  "text": "点击小屋查看升级和仓库。",
  "padding": 6,
  "dialog_position": [790, 10]
}
```

`target_path` 是从 `Main` 节点出发的路径。当前支持 `Control` 与 `Sprite2D` 目标；世界图片请指向具体的 `Sprite2D`，不要只指向其父级 `Node2D`。`padding` 是焦点外围留白；`dialog_position` 可省略，省略时使用场景中 `Dialog` 的静态位置。数组顺序就是播放顺序，无需导表。

在 `Main.tscn` 选中 `TutorialGuide` 后，可在 Inspector 中修改 `Steps File`、`Auto Start For New Save` 和默认 `Focus Padding`。从脚本指定开始步骤：

```gdscript
$TutorialGuide.start_guide()
$TutorialGuide.show_step("house")
```

引导完成或跳过会写入 `GameState.flags["tutorial_intro_completed"]`。当前自动启动依据是**启动时没有存档文件**，所以不会突然打断已有存档。

## 子窗口说明

这个遮罩属于主游戏窗口。Godot 的独立 `Window`（例如图鉴、种植和商店）拥有自己的绘制区域，主窗口遮罩不能覆盖它们。需要引导子窗口内部按钮时，应在对应子窗口中实例化同样的遮罩场景，或为子窗口添加专用引导层；步骤目标应改为该子窗口内的节点。
