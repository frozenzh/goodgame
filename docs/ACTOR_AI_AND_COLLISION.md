# 角色工作、休息与碰撞

角色脚底使用 `scenes/world/Worker.tscn/FootCollision`；只有脚底与场景静态障碍碰撞，动画帽子、鱼竿不会影响碰撞范围。不可进入区域均在碰撞层 2：

点击草地等非交互区域会发出手动移动指令。角色使用现有的道路优先寻路到点击点；到达后播放随机待机动作，再恢复日常行为。手动移动会取消待执行的工作指令并暂停当前钓鱼，未完成的一竿返还鱼饵；若目标不可达，原工作保持不变。交互建筑、土地、弹窗和 HUD 的点击不会触发地面移动。开启“空闲自动钓鱼”时，手动移动后会先休息一段时间，之后才可能恢复自动钓鱼。

可接受的手动目标会在点击位置播放短暂双圈涟漪，样式位于 `scenes/world/ClickRipple.tscn`。游戏主窗口失焦后，重新点回窗口的首次点击只用于激活窗口；下一次点击才会打断角色。钓鱼指令到达木板后立即抛竿并显示钓鱼进度，不再经过通用的三秒操作进度。

- `StaticWorldStrip.tscn/ResourceNodes/House/WalkBlocker`：小屋占地。
- `StaticWorldStrip.tscn/ResourceNodes/Workbench/WalkBlocker`：工具台占地。
- `PlotTile.tscn/StateVisuals/WalkBlocker`：每块土地的土壤区；主场景隐藏的第一块地禁用碰撞。
- `StaticWorldStrip.tscn/ResourceNodes/Pond/WaterBlocker/WaterPolygon`：池塘湖水；左侧钓鱼木板留作通道。

这些都是静态场景节点，可在 Godot 编辑器打开“可见碰撞形状”后拖动或缩放。改动碰撞范围时，应确认 `WorkerTargets` 的交互点仍在障碍外。角色前往任务点时优先沿下方安全通道绕行，再从下方靠近目标；钓鱼点从木板左侧接近。通道高度可在 `Worker` 的 Inspector 中调整 `safe_lane_y`，默认 210。

工作优先级：已下达指令（成熟地块收获、续种、手动指令）→ 无任务时自动钓鱼 → 鱼饵不足或休息期内随机徘徊。自动钓鱼需要背包有可用鱼饵；未选饵时会自动选择已有鱼饵。每钓到随机 8–12 条鱼休息 12–30 秒。手动“暂停钓鱼”会阻止自动恢复，手动“开始钓鱼”会解除暂停。工作抢占钓鱼时，当前未完成的鱼饵会返还。

种植弹窗的“收获后一直种植此种作物”默认勾选。勾选后，地块的 `planned_crop` 保存作物 ID；角色收获完成后，系统在金币足够时再派发播种指令。取消勾选则只种一轮。仓库已满时，成熟作物继续留在地里等待收获。

鱼图鉴按“普通、优秀、史诗、稀有”排列；现有数据中的 `common`、`uncommon`、`special`、`rare` 分别映射到这四个页签。所有鱼暂时共用同一枚鱼图标，未发现的鱼仍显示名称但使用淡色与“未发现”文字区分。

种植卡和鱼条目的排版分别在 `scenes/ui/CropChoiceCard.tscn`、`scenes/ui/FishCodexCard.tscn` 中，图标与文字是独立节点。种植卡的图标裁自对应 `mature_*.png` 的一株成熟作物，不另生图。
