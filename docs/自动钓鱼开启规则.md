# 自动钓鱼首次开启

新游戏的「空闲时自动钓鱼」默认不勾选。首次真实出售鱼并获得金币后，ShopSystem 自动开启此选项，同时清除手动暂停钓鱼标记；出售作物、牧场产品、打开商店或出售失败都不会触发。

一次性完成标记为 `GameState.flags.idle_auto_fish_first_sale_done`，随完整存档保存。首次开启后，玩家再手动取消勾选，后续卖鱼不会反复自动打开。手动提前勾选仍可使用。

旧存档保留已有显式勾选设置；根据已保存的卖鱼统计或新手引导的首次卖鱼标记补认一次性触发已完成。缺少该设置的旧存档，根据是否已卖过鱼选择默认值。不会读取或改写磁盘上的实际存档文件。

实现：`scripts/systems/shop_system.gd::sell_fish()`；默认值及旧存档兼容在 `scripts/autoload/game_state.gd`，初始数据在 `data/catalog/initial_state.json`。现有静态复选框仍为 `PondWindow/PondPopup/ContentSurface/PondContent/IdleAutoFish`。

未由 Agent 运行游戏或自动测试。请手动检查：新游戏默认未勾选 → 第一次成功卖鱼后勾选 → 手动关闭 → 再卖鱼仍关闭 → 保存读档后保持所选状态。
