# 成熟植物根部翻土

实际入口：`Main.tscn → StaticWorldStrip → PlotLayer/PlotNodes/Plot01..07`，地块实例使用 `scenes/world/PlotTile.tscn`。

在 `PlotTile.tscn` 选择 `StateVisuals/Mature…Cells/Cell_行_列/SoilContact`。各株均为静态场景实例，可单独修改 Transform 的位置、缩放，以及 Ordering 的层级。默认 Show Behind Parent 使土圈位于植株后、土地前。变异植株入口是 `StateVisuals/MutationVisual/Plant/SoilContact`。

- `Root Anchor`：相对植物不透明包围盒的归一化锚点，`(-1,-1)` 自动识别，`(0.5,1)` 为底部中央。
- `Root Width Ratio`：相对植物不透明包围盒的根宽，`0` 自动检测底部 8% 实心像素；例如 `0.2` 为不透明范围宽度的 20%，不是 PNG 画布宽度。
- `Thickness Ratio`：土圈厚度与根宽比例，默认 `0.12`；已补偿植株及地块的非等比缩放。
- `Texture` 子节点的位置、尺寸由脚本适配，请在外层 `SoilContact` 上手调。

编辑器选地块根节点，将 `Unlocked` 打开、`Preview Stage` 设为 `mature`，通过 `Preview Crop` 切换植物。需要在 Main 内单独调整某块地时，先对该 Plot 实例开启 Editable Children，再对 SoilContact 实例开启 Editable Children 即可编辑贴图样式。

脚本 `scripts/world/crop_soil_contact.gd` 缓存每张植物纹理底部 alpha 检测结果；蓝莓、番茄、草莓和茄子按素材茎部/贴地果实分布提供校正，实例中的 Root 参数优先。翻土裁到自身不透明范围，长度匹配根部接触宽度。它随成熟精灵的可见性、收获隐藏、换图和变异状态自动切换，苗期与空地没有翻土节点显示。

本次仅人工查看素材和静态代码/场景差异，未启动游戏、未运行自动测试；游戏内效果由用户验收。
