# 存档菜单与完整存档

编辑器运行使用项目根目录下的 `Saves`，当前为 `E:/GODOT/myfavorite/myfavorite/Saves`；发行版使用游戏可执行文件旁的 `Saves`。
只读取当前 `Saves` 文件夹，不再自动迁移或回退到旧 `user://save.json`，防止删除后旧进度再次出现。清空进度应先退出游戏，再删除 `Saves` 中的 JSON；运行中删除文件不会清除内存状态，后续自动保存会写回。

## 菜单与操作

- 开始菜单新增“存档”，位于“继续游戏”下方。
- 第一行固定为自动存档，后五行为手动槽，分别对应 `autosave.json`、`manual_01.json` 至 `manual_05.json`。
- 选中存档后可读取；手动槽可保存、替换或删除。保存/替换与删除均需二次确认。
- 自动存档在菜单中禁止手动保存覆盖和删除。新游戏确认后替换自动存档，手动槽保留。
- 每行显示保存时的电脑本地时间、累计运行时长和金币。旧存档无时长记录时从零开始累计，暂停与离线不计时。
- 设置右侧的暂停按钮可唤出开始菜单；继续游戏恢复原进度。暂停时平移活动生产时间戳，避免菜单停留导致作物、天气或施工进度跳变。
- 手动保存复用完整 GameState JSON；读取会重建场景，恢复队列并通过原有离线结算流程处理存档间隔。
- 写入使用临时文件替换，失败保留旧文件，不先删除原存档。

## 手动验收

此改动没有由 Agent 启动游戏、执行导表或修改实际存档。建议先备份旧存档，再手动检查：

1. 旧存档迁移后“继续游戏”和自动存档摘要是否正确。
2. 游戏中暂停一段时间，确认时长及生产倒计时不会跳进。
3. 向空手动槽保存，取消覆盖/删除时文件保持不变。
4. 金币或地块进度改变后读取手动槽，确认金币、队列、作物和建筑状态恢复。
5. 自动槽的保存/删除按钮不可操作，新游戏确认提示说明保留手动槽。
6. 切换屏幕和显示大小后，暂停按钮仍位于设置图标右侧。
