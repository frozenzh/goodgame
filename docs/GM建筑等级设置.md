# GM建筑等级窗口

在GM面板中点击「建筑等级」，打开静态子窗口；选择后点击「应用等级」写入当前进度并保存，不消耗金币。

- 小屋可设置1–4级，同步工坊关联等级、小屋外观、云层和牧场可见性，并按配置补齐对应小屋等级的鱼饵解锁。
- 商店可设置未建成或1–3级，同步建筑外观和高价收购栏位/报价。设置为未建成不清空库存。
- 工坊当前等级来自小屋配置，本窗口只读预览；没有新建独立等级字段。
- 降级保留已获得的物品和已解锁内容。对应建筑正在施工或有待执行的升级/完工任务时，先完成任务再修改，避免旧任务覆盖设置。

静态节点：`GMWindow/GMPopup/ContentSurface/BuildingLevelsButton` 为入口，`GMWindow/BuildingLevelsWindow` 为实际子窗口。也可单独打开 `scenes/ui/GMBuildingLevelsWindow.tscn` 调整每个标签、下拉框和按钮；实现脚本为 `scripts/ui/gm_building_levels_window.gd`。可见文字已进入 `excel/文本.xlsx` 及运行文本。
