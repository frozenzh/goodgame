## 最近完成

1. 地块增加可静态调整的播种/收获排队徽标；支持两种状态共存，并在角色真正劳动时切换为“播种中/收获中”。
2. 地块详情显示作物种类、排队格数、执行格数和剩余格数；批量播种/收获过滤已排队目标，避免重复预付。
3. 队列查询统一支持 `plant_cell`、`harvest_cell` 及旧 `plant`、`harvest`；浇水任务不计入播种状态。
4. 工作台制作任务与对应牧场喂食任务增加静态待执行徽标，并在实际劳动阶段切换为执行中文案。
5. 获得鱼飘字增加厘米尺寸行；图鉴详情增加独立尺寸底色标签、纪录文本与 `MAX` 标签。
6. 金币资源图标重做为细节更清晰的像素金币；游戏范围内接入透明木质箭头鼠标素材。
7. 鱼详情改为显示 `preferred_bait_type` 对应的鱼饵类型，并导表。
8. 天气移除雪天半透明覆盖矩形；`WeatherVisual` Inspector 有雨、雪、风三种直接色值参数。

## 开放事项与不确定性

- 上述最近改动尚未收到用户的游戏内视觉与长时间挂机验收。尤其雪天色调是否自然、鱼饵切换后的实际掉落分布，仍以用户测试为准。
- 用户明确要求即使方案文档提出测试，也不要由 Agent 执行测试；本轮功能只做文件实现并交由用户手动验收。
- 旧 `README.md`、`docs/GAME_DESIGN.md`、`docs/DATA_SCHEMA.md` 与现状不同，不宜作为新增功能的唯一依据；请优先查看项目档案和实际文件。
- 旧 Windows 包日期早于当前改动。若用户要分享当前版本，需重新导出；本次交接没有打包。
- 项目无 Git 仓库，无法用提交记录准确划分历史改动。不要假定未核对的旧需求已完成，也不要因为文档写着“已实现”就跳过当前场景检查。
