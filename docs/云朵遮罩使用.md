# 未解锁区域云朵遮罩

在 `scenes/main/Main.tscn` 展开 `StaticWorldStrip > CloudFog`。三个节点均是可独立移动和改大小的静态 `TextureRect`：

| 节点 | 显示时机 | 当前覆盖范围 |
| --- | --- | --- |
| `PlotEarlyCloud` | 小屋 1 级 | 第 3～7 块地及左侧 |
| `PlotLateCloud` | 小屋 2 级 | 第 6～7 块地及左侧 |
| `PastureCloud` | 小屋 1～2 级 | 牧场小屋及其左侧 |

目前的地块解锁配置是第 3～5 块地需小屋 2 级，第 6～7 块地需小屋 3 级。因此 3 级时先揭开牧场云层，让玩家看到建造中的牧场；牧场正式建成仍需小屋 4 级。

拖动节点的**右边缘**调整揭开云层的位置；拖动左、上、下边缘调整遮挡范围。云层随世界地图一起左右移动，不会压住资源栏和右侧图鉴、设置按钮。被云层覆盖的位置不会触发地面移动、建筑、地块或食槽点击；右键拖动地图仍可使用。

每块云的 `Material > Shader Parameters > Tile Count` 控制重复次数，`Edge Width` 控制右侧云边过渡宽度，`Opacity` 控制整体透明度。云纹使用镜像平铺，扩大节点时不会出现硬接缝。原始资源在 `assets/hd/world/cloud_fog_tile.png`，材质在 `shaders/cloud_fog.gdshader`。

编辑器默认显示小屋 1 级状态。想预览 2 级或 3 级，可暂时切换三个云节点的 `Visible`，但运行时仍由小屋等级自动设置可见性。
