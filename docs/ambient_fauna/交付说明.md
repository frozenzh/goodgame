# 蝴蝶与小鸟美术交付

资源目录：`res://assets/hd/world/ambient_fauna/`。独立静态预览场景：`res://scenes/world/AmbientFaunaArtPreview.tscn`。未修改世界场景及功能脚本，未启动 Godot、游戏或自动测试。编辑器中选中 AnimatedSprite2D 后，可在 SpriteFrames 面板播放；节点位置、scale、offset、animation、flip_h 均可独立调整。预览含原尺寸与5倍放大，peck 为单次动画，编辑器重播即可。

AnimatedSprite2D 均 centered=true。蝴蝶 offset=(0,0)；小鸟 offset=(0,-12)，使节点原点为落地点。小鸟飞行也沿用同一锚点，程序只移动节点；降落时不要换 offset。左右使用 flip_h，小鸟默认朝右；蝴蝶默认头朝上、背部俯视，左右镜像无需新帧。不要把图集再按高清动物纹理的0.04缩放，本图集已是逻辑像素尺寸。

小跳复用 stand，通过节点位移实现；peck 完成后回 stand。蝴蝶图集第二行后两格为空白，未引用。小鸟啄地过程保留脚底基线，头部下探为动作本身。飞行帧只做扇翅，路径、上下浮动、朝向由程序控制。

透明边缘检查：输出 alpha 仅0/255，没有白底、柔边和烘焙淡入；每帧四边均有透明留白，无贴边裁切。固定画布不按帧自动裁边。详细包围盒和帧区域见 manifest.json。生成原稿 *_imagegen_source.png 保留完整 RGBA；图集采用最近邻缩小并清理半透明边缘。已查看放大接触表；最终世界中的大小与观感由用户游戏验收。

生成方式：内置 imagegen，两次独立生成。最终提示词规格：

- 蝴蝶：透明背景、4列2行等格图集；前4格展开/半收/闭合/回展的飞行，第二行前2格停留，其余空白；暖金与奶油翼、深棕身体和阶梯轮廓，俯视，约16px逻辑造型，身体中心固定；参考项目鸡和胡萝卜色板与像素颗粒；无字、无网格、无阴影、无柔焦、无透明淡入。
- 小鸟：透明背景、4列2行等格图集；前4格上抬/半落/下拍/回抬飞行，第二行站立/低头/触地/抬头；朝右略俯视，栗棕帽、棕背、赭色翼、奶油胸、黑像素眼和短棕喙，约22×20px逻辑造型；固定身体尺度和脚底基线；参考项目鸡的暖色深棕阶梯描边，无羽毛细节、文字、阴影、柔边或渐变。

功能约定供接入读取：晴天；蝴蝶每个有作物大地块1–3只（苗期、成熟未收获均计），全图10只且尽量每块至少1只；飞入淡入0.8–1.2秒，活动15–25秒、补充45–90秒。鸟每群2–5只、全图5只，活动10–20秒、群间隔60–120秒；两类额度独立。首批10–20秒错峰，雨雪风2–3秒飞离；无声、避UI和工作点，鸟不落水。此交付不实现生成逻辑。

## 五色扩展

五种配色：gold 金黄、blue 天蓝、pink 粉、purple 紫、mint 薄荷绿。各自文件为 `butterfly_{color}_atlas.png` 与 `butterfly_{color}_frames.tres`，均在原资源目录。完整列表见 `res://assets/hd/world/ambient_fauna/butterfly_colors.json`。五色对照场景 `res://scenes/world/ButterflyColorPreview.tscn`。

直接基于已交付图集逐像素映射翼色，未重新生成造型。五组 alpha 逐像素完全相同；身体、触须、描边保持原样。帧区域、fly/perch 动画、帧率、枢轴与显示尺寸全部沿用基础版。原版 butterfly_frames.tres 保留兼容。

程序在每只蝴蝶创建时等概率随机选一组 SpriteFrames，保存至该只实例整个生命周期；切换 fly/perch 不重新随机颜色，不对整个精灵 modulate 染色。全局淡入仅改变 modulate.a。五色共用原全图10只限额，不按颜色分别计数。功能规则仍按本文前述执行。
