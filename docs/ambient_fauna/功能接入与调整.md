# 非雨天蝴蝶与小鸟

实际实例：`Main/StaticWorldStrip/AmbientFauna`，独立场景 `scenes/world/AmbientFauna.tscn`。可直接打开独立场景编辑，也可在 Main 中展开可编辑实例。世界横移和显示大小变化由父级一起变换，范围中心会跟随对应地块。

## 静态可调节点

- `PlotRanges/Plot01..Plot07/Area`：蝴蝶活动矩形，出现点和消失点均在该矩形周界随机选取。拖动、缩放该矩形调整范围；父节点自动跟随同名地块，不需要改父节点位置。
- `BirdLandings/Fences/BackFence*`：高权重落点（默认60%），跟随画面最上方三段栅栏。各 `Perch` 是柱顶落脚点；同一级内随机选取，屋后被遮住的点会跳过。
- `BirdLandings/Roofs/CottageLevel1..4`、`Workbench`、`ShopLevel1..3`、`PastureBarn`：中权重落点（默认30%），分别跟随实际可见级别的屋顶精灵。每个屋顶有两个静态 `Perch`，可直接拖动。未显示或未建成的建筑不提供屋顶落点。
- 各地块范围下的 `BirdLandingLeft`、`BirdLandingRight`：低权重地面落点（默认10%），即使栅栏和屋顶可用也可能被选中；程序另外排除水面、云遮挡、角色工作点和靠近角色的位置。
- `EntryPoints/Point01..08`、`ExitPoints/Point01..08`：8个小鸟飞入点和8个飞出点，可直接拖动或隐藏。飞入时从目标落脚点最近的两个可见飞入点随机选择；飞离时从小鸟当前所在位置最近的两个可见飞出点随机选择。直接使用Marker位置，不另加坐标抖动；蝴蝶不使用这些点。
- `WaterExclusion`：禁止鸟落地的水面矩形，随池塘改动时同步调整。
- `Butterflies/Slot01..14`、`Birds/Slot01..10`：固定 AnimatedSprite2D 槽位，运行时复用。可调整显示缩放；蝴蝶和小鸟当前缩放均为0.7（相较原尺寸缩小30%）。位置和显隐由活动逻辑控制。鸟的 offset `(0,-12)` 使节点原点对应脚底，不要随飞行/落地更改。

Area、WaterExclusion 是编辑器专用 ReferenceRect，不会在游戏内绘制边框。所有槽位默认隐藏，需要查看素材时可单独打开美术预览场景 `AmbientFaunaArtPreview.tscn` 或 `ButterflyColorPreview.tscn`。

## 配置与规则

`excel/环境生物.xlsx` 的「参数」页是权威源表，已有 Windows 一键导表会自动导出 `data/config/ambient_fauna.json`。时间以秒计，距离以世界逻辑像素计。数量硬上限受静态槽位数量约束，当前静态池支持蝴蝶 14、鸟 10；继续提高数量前需要补齐静态槽位。

仅雨天禁止生成，晴天、雪天和多云均可活动。蝴蝶只由成熟作物触发：每块地首次出现成熟未收获作物后，独立随机等待 5–10 秒生成一批。新游戏最初定制的成熟小麦同样适用，不等待小鸟的首次随机事件；种子和叶片不会触发。

每块成熟地目标为 1–3 只蝴蝶，全图上限继续由 butterfly_cap 控制（当前14），先照顾每块一只。成熟作物存在时，每只蝴蝶出现后独立随机活动10–20秒，然后从地块边缘飞离淡出；此时间包含飞入和最后的正常消失动画。完整消失后，该只独立随机等待5–10秒再出现，不等待整块地的其他蝴蝶消失。

最后一株成熟作物收走后，取消该地块所有待重现记录，已有蝴蝶在1–5秒内飞往地块边缘并淡出；部分收割但仍有成熟作物时保留个体循环。再次出现成熟作物时重新等待首次5–10秒。雨天取消待重现并按天气离场时间飞离，雨停且仍有成熟作物时重新触发。五色等概率选取，每次出现选择一次，活动期间不变色；静态缩放0.7不变。

源表 butterfly_mature_delay_min/max 控制成熟后的首次等待（5/10）；butterfly_life_min/max 控制个体出现到完整消失时间（10/20）；butterfly_respawn_delay_min/max 控制单只消失后的重现等待（5/10）；butterfly_exit_seconds 控制正常消失动画长度（1秒，包含在寿命内）；butterfly_harvest_exit_min/max 控制收割离场（1/5）。旧 butterfly_cycle 参数已替换。GM 手动按钮可跳过成熟等待及个体重现等待，但没有成熟作物仍不生成。

小鸟每群 2–5 只、独立全图上限由 bird_cap 指定（当前10）。按类别权重随机选择：默认上排栅栏60%、屋顶30%、地面10%；再在选中类别的安全落点中均匀随机。类别权重不受 Marker 数量影响；只有某类别无安全落点时，才按剩余类别的相对权重重新分配概率。不同落点错峰飞入，停留后执行 2–3 次啄地、转向或小跳，共 10–20 秒；整群离开后冷却 60–120 秒。安全落点不够时延后，不能少于两只单独出现。落脚点跟随原资源缩放与位移；屋顶所属建筑隐藏或升级后，原处的鸟自然飞离。

首次环境随机生成只包含小鸟，其等待时间仍由 initial_wait_min/max 控制。雨天停止两类新生成，已有个体按 weather_exit_min/max 飞离；未显示的入场槽取消。雨停后，仍有成熟作物的地块重新等待成熟触发时间。所有入场、活动和离场槽均占额度；暂停冻结计时和动画，继续后不补刷。读档或新游戏清空临时活动，再按当前成熟作物与鸟群时钟分别处理。

## 用户手动查看

小鸟额外转点：每只每批随机0–2次，在相近的其他静态落点间飞行。默认最大距离180个世界逻辑像素，落地等待1–2秒后起飞，单次弧线飞行0.8–1.6秒、弧高10像素。选择仍使用栅栏/屋顶/地面类别权重，排除其他鸟占用的位置；没有安全邻点时取消转点。啄地或小跳结束后再起飞，必要时延长本批活动，让额外飞行有完成时间。参数位于源表 bird_relocation_*；无需新增或移动落点节点。

本次只做文件静态检查，未运行 Godot、游戏或自动测试，也未执行完整导表。

1. 新游戏非雨天时观察初始成熟小麦：5–10 秒内生成蝴蝶；只有种子/叶片的其他地块不生成。小鸟按自身首次等待独立出现。
2. 查看 Remote 场景中的静态槽：蝴蝶最多 14、鸟最多 10（离场和延迟入场都计入）；不同地块共享额度。
3. 保持成熟作物不收，观察各只蝴蝶分别活动10–20秒消失，再分别等5–10秒出现。部分收割时循环继续，最后一株成熟作物收走后1–5秒内消失且不再出现；再次成熟重新等待首次5–10秒。
4. 切换雪天、多云，确认不打断活动；切换雨天，观察按源表 weather_exit_min/max 时间飞离；暂停后确认活动冻结，恢复后没有集中补刷。
5. 切换大中小显示、横移场景，确认范围仍跟随农田，落点不进入水面、工作点及 UI。
6. 观察小鸟有时不转点、有时在附近静态点之间额外飞行1–2次；确认起飞、扇翅、落地衔接，不与其他鸟重叠，雨天仍会飞离。
