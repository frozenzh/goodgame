# 六步新手指引静态布局

打开 `scenes/main/Main.tscn`，展开 `TutorialGuide/OverlayRoot`，也可以直接打开 `scenes/ui/TutorialGuide.tscn`。

六套独立节点对应：

| 节点 | 步骤 |
| --- | --- |
| Step01Harvest | 收获初始地块 |
| Step02Workbench | 完成工坊修建 |
| Step03Bait | 工坊制作鱼饵 |
| Step04Fishing | 前往钓鱼 |
| Step05Shop | 完成商店修建 |
| Step06Sell | 售卖鱼 |

编辑时只打开需要编辑的 Step 的 Visible，关闭其他步骤，避免六层遮罩重叠；运行时会按当前步骤切换可见性。

- `FocusFrame`：直接调整 Position、Size（或四个 Offset），控制高亮范围及首次点击后隐藏的区域。
- `Dialog`：直接调整文本框位置和尺寸；运行时跟随目标的坐标变化，并限制在窗口边界内。
- `Dialog/Content/Title`、`Message`：分别调整字号、颜色；内容进入文本表。
- `MaskTop/MaskLeft/MaskRight/MaskBottom`：颜色可独立调整，矩形范围由 `tutorial_step_layout.gd` 跟随本步 FocusFrame，编辑器中也会更新。
- 六步的边框和对话框背景使用独立样式资源，修改其中一套不会同步改变其他步骤。

`data/tutorial/intro.json` 只保存顺序、对应静态节点、文案 ID 和完成条件。每个 Step 的 Target Path 指向对应地块或建筑；运行时根据该目标相对场景初始坐标的变换，换算高亮框和文本框的位置，保留编辑器设置的相对偏移。
首次点击当前 FocusFrame 后整层提示隐藏，等待真实操作完成才显示下一套；该等待状态仍随存档保存。

此改动未运行游戏或导表，具体高亮位置可在实际主场景中继续手动微调。

## 显示大小与目标跟随

六套静态节点保留，布局以“大”显示的场景坐标为基准。运行时每步从原始保存的布局计算，不累加上一次换算结果，切换大/中/小或横移场景时不会逐次漂移。

- Step01Harvest 跟随 Plot01，Step02Workbench / Step03Bait 跟随 Workbench，Step04Fishing 跟随 Pond，Step05Shop / Step06Sell 跟随 ShopBuilding。
- 继续在对应 Step 的 FocusFrame、Dialog 上直接调整位置和尺寸，修改后重新运行生效；不要为了小显示另外改一套布局。
- 每个 Step 的 Target Path 可指定目标，Follow Target 控制跟随，Keep Dialog On Screen 控制文本框边界保护，Screen Margin 是画布像素内边距。
- 文本框到达窗口边缘后会限制在画布内；如果因此盖住原本分开的高亮区域，优先切换到高亮框另一侧。
- 编辑器里仍只实时更新四周遮罩，运行时换算结果不会写回保存的场景布局。

此变更未由 Agent 启动游戏验证。请手测大/中/小切换、场景左右移动和首次点击隐藏，再确认完成操作后下一步位置正确。

## 对话框内容自适应

六步默认开启 Auto Fit Dialog Height。Dialog 的宽度和位置仍可独立设置，高度根据标题、正文换行、操作行及背景内边距自动收紧；正文不再分摊多余高度。编辑器和运行时均会更新。若需要某一步使用固定高度，可关闭该 Step 的 Auto Fit Dialog Height。
